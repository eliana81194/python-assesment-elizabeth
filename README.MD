## Description of Files

| File | Description |
|------|--------------|
| `task2_syntax_pep8.py` | Zen of Python principles (2 explained as a docstring), PEP 8-compliant script, comments, snake_case variables, and multiple variable assignments. |
| `task3_data_types.py` | Demonstrates int, float, bool, string (concatenation/slicing/len), list (append/remove/indexing), tuple (immutability), set (duplicate removal), dictionary (access/add/delete), and type casting. |
| `task4_control_structures.py` | If-elif-else grade classification, for loop over a fruit list, while loop printing even numbers, break/continue with a student ID search example, and a nested-loop 3x3 multiplication table. |
| `task5_functions.py` | Built-in functions (`len`, `max`, `sorted`), a `calculate_area()` function, default parameters, `*args` summation, a lambda squaring function used with `map()`, and local vs. global variable scope. |
| `task6_oop.py` | `Animal` class with `__init__`, `speak()`, an instance counter class variable, a `Dog` subclass demonstrating inheritance (overriding `speak()`), and encapsulation via a private `__age` attribute with getter/setter methods. |
| `task7_numpy_pandas_matplotlib.py` | NumPy array creation, mean/sum, reshape, and element-wise arithmetic; a Pandas student DataFrame with a marks filter; a bar chart of names vs. marks and a line graph of a marks trend, saved as `task7_charts.png`. |
| `task8_net_salary_calculator.py` | Captures employee details, calculates gross pay, PAYE (bracket-based), NHIF, NSSF, total deductions, and net pay, then displays a formatted payslip. |
| `task9_disease_diagnosis.py` | Displays a hospital welcome message, captures patient details and two symptoms, matches symptom pairs to a diagnosis (Malaria, Typhoid, Pneumonia, Diabetes), handles unrecognized combinations, and displays a formatted report. |
| `task10_ml_knn_naive_bayes.py` | Loads the Iris dataset, splits it into train/test sets, trains and evaluates a KNN classifier (accuracy + classification report) and a Gaussian Naive Bayes classifier (accuracy + confusion matrix), with written explanations of Euclidean distance and Bayes' theorem. |
| `requirements.txt` | Lists the Python libraries required to run the scripts. |

## How to Run
Each script can be run independently, e.g.:
```bash
python task3_data_types.py
```

## Requirements
Install dependencies with:
```bash
pip install -r requirements.txt
```
